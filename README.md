# 🍽️ Simple Order Form (WhatsApp Integration)

A simple web-based order form that allows users to select menu items, calculate totals automatically, and send orders directly via WhatsApp.

## 🚀 Features

- Add / remove item quantity
- Auto update order summary
- Real-time total price calculation
- Form validation (customer data)
- WhatsApp message integration
- Clean and responsive UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla JS)

## 🧠 How It Works

1. User selects menu items using + / - buttons
2. System updates summary in real-time
3. User fills in order form
4. On submit:
   - Data is collected
   - Order is formatted into a message
   - Redirected to WhatsApp with pre-filled message
